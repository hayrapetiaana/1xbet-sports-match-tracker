# ⚽ 1xBet & Multi-Bookmaker Sports Match Tracker

A modern web application tracking upcoming prematch and live sports matches across major bookmakers (1xBet, Fonbet, Vbet, Marathon, Bet365, Bwin), featuring time & sport filtering, direct match-checking tools, bilingual support (EN/RU), and dark/light modes.

## ✨ Features

- **Multi-Bookmaker Feeds**: Aggregates match listings from 1xBet, Fonbet, Vbet, Marathon, and more.
- **Filtering & Search**: Filter by sport, start times, bookmaker sources, and search by team names.
- **Match Checker**: Real-time comparison and match-up validator.
- **Theme & Localization**: Dark and Light themes with instant flash-prevention, plus English and Russian UI support.
- **Fast & Responsive**: Built with Next.js App Router, React 19, and Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: React 19, Tailwind CSS v4
- **Language**: TypeScript
- **Database ORM**: Drizzle ORM (PostgreSQL)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/hayrapetiaana/1xbet-sports-match-tracker.git
cd 1xbet-sports-match-tracker
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
